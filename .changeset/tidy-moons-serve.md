Migration complète des styles vers les tokens de thème : toutes les couleurs, rayons, ombres, élévations et typographies des composants utilisent désormais les variables CSS du thème (contrat Tweakcn + clés étendues EGEN) avec des replis dérivés du contrat de base. Fini les valeurs en dur : le clair/sombre et les thèmes personnalisés s'appliquent automatiquement à tous les composants.
