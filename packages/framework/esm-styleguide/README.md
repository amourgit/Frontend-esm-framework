# egen-esm-styleguide

The styleguide for Egen.

Our frontend UI is built with [Tailwind CSS](https://tailwindcss.com/) and our own base components (`src/ui`, adapted from [shadcn/ui](https://ui.shadcn.com/) and [Radix](https://www.radix-ui.com/)). 

Check out the [full, detailed styleguide in Zeplin here](https://egen.alpha.vercel.com/design-system) (let us know if you require an invitation) and our design documentation.
